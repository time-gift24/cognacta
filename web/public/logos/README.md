# Brand marks

Monochrome provider and integration marks, rendered as CSS masks in the current
text colour.

- Source: [Simple Icons](https://simpleicons.org/) (CC0 1.0).
- Brand names and logos are trademarks of their respective owners; they are used
  here only to identify the providers in the demo integration directory.
- Files are stored locally so production builds do not depend on a third-party
  image CDN.
